Result contract

Every input ends in a decision-ready state.

Acceptance rules are agreed for the bounded route. Technical completion alone does not make a result accepted.

  1. 1RouteValidate the input and assign eligible execution.
  2. 2RetryRecover bounded failures without hiding terminal state.
  3. 3CheckValidate the returned fields against the route contract.
  4. 4ReturnAccepted, rejected or review-required output.
