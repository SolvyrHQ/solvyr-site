Claim boundary

What this sample proves—and what it does not.

This demonstrates the plain-text embedding branch: clean public text preparation, stable chunk identity, bounded async scheduling, embedding generation, result retrieval, input validation, and run evidence for a tiny workload. It is not a PDF-extraction, OCR, structured-extraction, retrieval-quality, scale, distributed-performance, customer-data, cost, or SLA benchmark. The model digest was not returned and is marked unavailable in the report.
